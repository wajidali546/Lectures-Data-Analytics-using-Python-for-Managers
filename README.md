# Data Analytics Using Python for Managers

## 📘 About the Course

This repository contains teaching materials, Python examples, datasets, and practical exercises for the course **Data Analytics Using Python for Managers**, taught at the **Fortune Institute of International Business (FIIB), New Delhi**.

The course focuses on helping management students understand how Python can be used to analyse business data, identify patterns, solve managerial problems, and support data-driven decision-making.

## 🎯 Learning Objectives

By working through the materials in this repository, students will learn to:

- Understand basic Python programming for data analytics.
- Import, clean, and prepare business datasets.
- Perform Exploratory Data Analysis (EDA).
- Identify missing values, duplicates, and outliers.
- Apply descriptive statistics and correlation analysis.
- Create visualisations to communicate business insights.
- Interpret analytical results for managerial decision-making.

## 🛠️ Tools and Technologies

- **Python** – Data analysis and programming
- **Pandas** – Data manipulation and cleaning
- **NumPy** – Numerical computation
- **Matplotlib and Seaborn** – Data visualisation
- **Jupyter Notebook / Google Colab** – Practical coding and experimentation
- **Excel and CSV** – Business datasets and data handling
- **GitHub** – Version control and collaboration

## 📂 Repository Contents

The repository may include:

- Lecture notes and Python notebooks
- Business datasets for practical exercises
- Data cleaning and preprocessing examples
- Exploratory Data Analysis (EDA)
- Statistical analysis and visualisation
- Assignments and case-based exercises
- Business questions and managerial interpretations

## 💼 Business Applications

Students will practise using data to answer questions such as:

- Which products or cities generate the highest revenue?
- Are sales increasing or decreasing over time?
- Which factors are associated with customer spending?
- How do missing values and outliers affect business analysis?
- What patterns can managers identify from data visualisations?
- How can analytical findings support better business decisions?

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the notebooks using Google Colab or Jupyter Notebook.
3. Download the dataset associated with the relevant exercise, if required.
4. Run the Python code step by step.
5. Interpret the outputs and connect the findings to the business problem.

## 👨‍🏫 Teaching Approach

The course follows a practical, business-oriented approach. Students begin with business questions, work with real-world-style datasets, apply Python techniques, and interpret the results in simple managerial language.

The emphasis is not only on writing code but also on understanding **what the data reveals, why the findings matter, and how managers can use them to make informed decisions**.

## 📌 Intended Audience

This repository is designed primarily for management students, PGDM/MBA learners, beginners in Python, and anyone interested in applying data analytics to business problems.
